# Aqua Alert Aktau

Создай мобильное веб-приложение "AQ SU" для сообщений об утечках воды в городе Актау. Экраны: 1. Карта города с маркерами заявок (Leaflet, центр Актау) 2. Форма "Сообщить об утечке": загрузка фото, выбор точки на карте, описание 3. Экран результата: вероятность утечки в процентах, масштаб, приоритет 4. Список "Мои заявки" со статусами 5. Панель диспетчера со всеми заявками Дизайн: мобильный, крупные кнопки, сине-бирюзовые цвета, интерфейс на русском языке. Данные хранить в localStorage.
